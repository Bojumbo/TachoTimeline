## 📌 1. Можливості та правила Регламенту ЄС 561/2006

Додаток в реальному часі відстежує 4 ключові рівні обмежень режиму праці та відпочинку водіїв:

1. **Безперервне кермування (Continuous Driving)**:
   - Максимум: **4 години 30 хвилин**.
   - Обов'язкова пауза: **45 хвилин** безперервно АБО спліт: спочатку мінімум **15 хв**, потім не менше **30 хв** (порядок `30 + 15` суворо заборонений).
   - Попередження за 30 хвилин до дедлайну зупинки.

2. **Щоденне кермування (Daily Driving)**:
   - Стандарт: максимум **9:00 годин**.
   - Подовження: до **10:00 годин** максимум **2 рази** між двома щотижневими відпочинками.

3. **Щоденний відпочинок та «Зміна» (Daily Rest & 24h Window)**:
   - Відлік вікна 24 години від початку робочого дня водія.
   - **Регулярний відпочинок**: 11 годин (робоча зміна до **13 годин**). Або спліт: 3 год + 9 год (зміна до 15 годин).
   - **Скорочений відпочинок**: 9 годин (робоча зміна до **15 годин**) — дозволено максимум **3 рази** між щотижневими відпочинками.

4. **Щотижневі норми (Weekly Limits)**:
   - Кермування за календарний тиждень: максимум **56 годин**.
   - Кермування за 2 послідовні тижні: максимум **90 годин**.
   - Обов'язковий щотижневий відпочинок: не пізніше ніж через **6 періодів по 24 години (144 години)** після попереднього щотижневого відпочинку.

## 📁 2. Структура репозиторію

```text
tacho-planner/
│
├── backend/
│   ├── app/
│   │   ├── __init__.py
│   │   ├── main.py          # Точка входу FastAPI, маршрутизація, Seed Demo
│   │   ├── rules.py         # Серце розрахунків норм Регламенту ЄС 561/2006
│   │   ├── models.py        # SQLAlchemy моделі (User, Activity) та Pydantic схеми
│   │   └── auth.py          # Безпека, JWT-токени, хешування паролів, гостьовий режим
│   ├── requirements.txt
│   └── Dockerfile
│
├── frontend/
│   ├── index.html           # Інтерфейс кабіни тахографа зі шкалою
│   ├── app.js               # Малювання шкали (vis-timeline), таймери, API
│   ├── style.css            # Преміальна темна тема в стилі бортового комп'ютера
│   └── nginx.conf           # Конфігурація Nginx та проксі /api/ -> backend
│
├── docker-compose.yml       # Повний стек (Backend + Frontend + SQLite том)
└── README.md
```

## 🚀 3. Швидкий запуск на сервері через Docker

### Крок 1. Підготовка сервера (Ubuntu/Debian)
```bash
sudo apt update && sudo apt install -y git docker.io docker-compose-v2
```

### Крок 2. Клонування репозиторію
```bash
git clone https://github.com/ВАШ_ЛОГІН/tacho-planner.git
cd tacho-planner
```

### Крок 3. Запуск контейнерів
```bash
docker compose up -d --build
```

Додаток буде доступний:
- **Веб-інтерфейс**: `http://IP_ВАШОГО_СЕРВЕРА:8975/`
- **Інтерактивна документація Swagger**: `http://IP_ВАШОГО_СЕРВЕРА:8975/docs`

### Оновлення коду після змін на GitHub:
```bash
git pull origin main
docker compose up -d --build
```

## 💻 4. Локальний запуск для розробки (без Docker)

### 1. Бекенд:
```bash
cd backend
python -m venv venv

# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

### 2. Фронтенд:
Відкрийте `frontend/index.html` у браузері або скористайтеся вбудованим маршрутом FastAPI за адресою `http://localhost:8000/`.

## 🎮 5. Керування тахографом

- **4 Великі кнопки режимів**:
  - 🟢 **КЕРМО (DRIVE)** — клавіша `1`
  - 🟡 **РОБОТА (WORK)** — клавіша `2` (молотки: завантаження / огляд)
  - 🔵 **ГОТОВНІСТЬ (POA)** — клавіша `3` (пасажир / очікування)
  - 🟣 **ВІДПОЧИНОК (REST)** — клавіша `4` (ліжко / пауза)
- **«Демо Рейс»**: кнопка в шапці миттєво генерує типовий робочий день далекобійника для наочної перевірки графічної шкали та таймерів.
- **Масштабування шкали**: кнопки «24 Години», «48 Годин», «7 Днів» або жести зуму мишкою/пальцями на тачскріні.
- **Редагування**: клікніть на будь-який відрізок на шкалі або в таблиці для зміни часу чи опису.
